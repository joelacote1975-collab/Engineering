── v7 (ก่อนเริ่มแก้) ──────────────────────────────────────────────────────────
ปัญหาที่พบ:
  1. ชื่อ Point ยาวกว่า 8 ตัวอักษรไม่ถูกตัด → ทำให้ format DMIS ผิด
  2. Deduplication ใช้ชื่อเต็ม แต่ DMIS ใช้แค่ 8 ตัว → label ซ้ำในไฟล์
  3. ความยาวบรรทัด data = 84 chars (เกิน DMIS standard 80 chars)
  4. Header/End line = 81 chars
  5. Comment line ไม่มี DMIS label (ควรเป็น $$ format)
  6. Grid search วนทุก face ทุก point → ช้า (ไม่มี pre-filter)
  7. UVW ออกมาเป็น (0,0,1) ทุกจุด → Normal ผิด

── v8 (แก้ format issues) ──────────────────────────────────────────────────────
แก้ไข:
  [1] ตัดชื่อ label ด้วย name[:8] ทุกครั้ง
  [2] Deduplication ทำบน 8-char label แทนชื่อเต็ม
  [3] ลด padding ใน data line → 80 chars พอดี
  [4] แก้ Header/End padding → 80 chars
  [5] เปลี่ยน comment line เป็น $$ format
  [6] เพิ่ม pre-filter: sort face ตาม distance → เอา top 50
ผล: DMIS format ถูกต้อง แต่ UVW ยังเป็น (0,0,1) ทุกจุด

── v8b (พยายามแก้ AskFaceProps) ───────────────────────────────────────────────
สาเหตุที่สงสัย: AskFaceProps ส่ง UV ผิด signature (u, v แยก แทนที่จะเป็น [u,v])
แก้ไข:
  - เปลี่ยน AskFaceProps(face_tag, u, v) → AskFaceProps(face_tag, [u, v])
  - ปรับ pre-filter ใช้ center UV evaluation แทน centroid
  - เพิ่ม MAX_CANDIDATES เป็น 120
ผล: ยังไม่ได้ผล — nearest dist=inf ทุกจุด

── Diagnostic v2 ───────────────────────────────────────────────────────────────
ตรวจสอบ dir(uf.Modl) และ dir(face object)
ผลที่พบ:
  - uf.Modl ไม่มี face evaluation methods เลย
  - NXOpen.Face object ไม่มี Normal / Evaluate method
  - พบ uf.Evalsf ใน submodule list → นี่คือ Surface Evaluator module

── Diagnostic v3 ───────────────────────────────────────────────────────────────
ทดสอบ uf.Evalsf methods
ผลที่พบ:
  uf.Evalsf methods:
    AskFaceUvMinmax, AskMinimumFaceDist, Evaluate,
    FindClosestPoint, FindClosestPoint2, Initialize, Initialize2, Pos3
  - Initialize(face_tag) ทำงานได้ → คืน PointerWrapper
  - Evaluate(order, [u,v]) ทำงานได้ → คืน ModlSrfvalue_Struct
      .SrfPos, .SrfDu, .SrfDv, .SrfUnormal (ค่า garbage), .SrfD2u ฯลฯ
  - SrfUnormal ไม่น่าเชื่อถือ → ต้องคำนวณ Normal จาก SrfDu × SrfDv เอง

── Diagnostic v4 ───────────────────────────────────────────────────────────────
ทดสอบ FindClosestPoint และ cross product normal
ผลที่พบ:
  FindClosestPoint(evaluator, [px,py,pz]) → EvalsfPos3_Struct
    .Distance = ระยะห่างจาก query point ถึงจุดใกล้สุดบน face
    .Uv       = [u, v] parameter ของจุดใกล้สุด
    .Pnt3     = [x, y, z] พิกัด 3D ของจุดใกล้สุด
  AskFaceUvMinmax(face_tag) → memory access violation (ห้ามใช้!)
  Cross product normal ทำงานได้ถูกต้อง

── v8c (สำเร็จ ✓) ──────────────────────────────────────────────────────────────
แก้ไข:
  - ลบ uf.Modl code ทั้งหมดออก
  - ลบ Grid search ทั้งหมดออก
  - ใช้ uf.Evalsf แทนทั้งหมด
  Algorithm ใหม่ (3 บรรทัด):
    ev  = uf.Evalsf.Initialize(face.Tag)
    cp  = uf.Evalsf.FindClosestPoint(ev, [px, py, pz])  → .Distance, .Uv
    srf = uf.Evalsf.Evaluate(ev, 1, cp.Uv)              → .SrfDu, .SrfDv
    normal = normalize(SrfDu × SrfDv)
  วนทุก face หา face ที่ cp.Distance น้อยสุด = face ที่ point อยู่บนนั้น
